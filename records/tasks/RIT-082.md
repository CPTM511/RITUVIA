# RIT-082: Public numerology calculator and result UI

- Backlog item: RIT-082
- Related records: D-064

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

An anonymous English user can calculate Life Path, Birthday Number, and Personal Year at
`/en/readings/numerology` through the approved server-authoritative engine, inspect every formula
step, reset the sensitive input, and understand that the result is symbolic rather than
predictive.

## Scope

Included: the reviewed English route; strict same-origin private POST API; explicit ASCII ISO birth
date and four-digit target year; approved catalog and engine binding; loading, empty, validation,
offline, unavailable, retry, reset, and mobile states; visible arithmetic and version evidence;
keyboard/focus/semantic/contrast/reduced-motion checks; no-script fail-closed behavior; route/API
allowlisting; production OpenAPI correction; focused component, API, proxy, accessibility, and
browser evidence.

Excluded: name or Expression Number, transliteration, non-English publication, non-Gregorian input,
AI prose, predictions, persistence, database changes, analytics, account merge, intention creation,
SEO cluster publication, deployment, and public production launch.

- [x] Formatting, linting, affected typecheck/build, architecture, records, generated evidence,

## Risks and rollback

Birth date is sensitive even when no account or persistence exists. The API therefore accepts only
a bounded same-origin body, emits no content-bearing error, returns private no-store responses, and
never places inputs in URL, metadata, storage, analytics, or logs. Formula drift is contained by
the exact approved catalog and engine versions.

There is no migration, retained data, provider, payment, AI, or deployment. Roll back by removing
the route, API, server adapter, UI/messages/styles/tests, restoring the API contract and proxy
allowlist, and reverting this task/status evidence. RIT-081 remains independently usable.
