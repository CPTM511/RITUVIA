# RIT-129: Provider-free staging and Gate H evidence contract

- Backlog item: RIT-129
- Related records: D-104, D-109
- Owner approval: Not required for a repository-local provider-neutral evidence contract. Every
  hosted staging resource, provider/credential use, deployment, DNS/public access, Gate H approval,
  Beta release, production mutation, or launch remains separately Owner-gated.

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

Implement one no-secret local contract that binds an exact protected-Beta candidate and eight
staging/Gate H controls to verified evidence files, derives fail-closed status, and remains truthful
that current Gate H is incomplete without deploying or activating any provider.

## Scope

Included: strict candidate/D-104 snapshot, eight evidence controls, derived projection, private
exclusive reports, verifier, tests, and records. Excluded: hosted resources, providers/credentials/
network, managed PITR/pager/DAST/pentest, product/Admin surface, migration, invites, deployment,
DNS, Gate H/I/J approval, launch, RIT-127, and RIT-130.

## Acceptance criteria

- [x] One exact contract binds candidate revision/clean state, Node/pnpm, artifact/configuration/
      lockfile/Corresponding Source digests, isolated staging profile, and D-104 thresholds.
- [x] Eight ordered controls require the correct staging/provider/external evidence kinds and fixed
      freshness windows; local/CI evidence cannot masquerade as Gate H evidence.
- [x] Evidence intake rejects unknown/private fields, getters, unsafe paths, symbolic links,
      oversize files, duplicate kinds, digest/revision/environment/time drift, and D-104 drift.
- [x] State is derived: failed evidence fails; missing/stale/dirty/WORKTREE evidence blocks; a
      complete package reaches only Owner review and never deployment authorization.
- [x] The generator reads bounded regular files, verifies SHA-256, writes new mode-0600 JSON and
      Markdown only, and never overwrites evidence.
- [x] The runbook covers terminal entry, no Web/Admin Button, input/output, blockers, recovery,
      Owner gate, and rollback; independent review and complete gates pass.

## Verification evidence

- Two focused files pass eight tests; observability typecheck and `pnpm check:staging-gate-h` pass.
- Independent review confirms contract closure while external/staging/Gate H evidence stays blocked.
- The complete pinned Node.js 26.5.1 / pnpm 11.13.1 `pnpm check` gate exits successfully, including
  the 16-package production build and 61-page Web build.

## Risks and rollback

The contract verifies structure/provenance/bytes, not an attestation's substance; independent and
Owner review remain mandatory. Rollback removes this local slice and records. No external state
requires reversal.
