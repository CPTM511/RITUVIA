# RIT-011: Semantic design tokens and accessible component primitives

- Backlog item: RIT-011
- Related records: D-024

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

Public and future product interfaces share one tested, locale-safe visual and interaction contract
for core controls instead of reimplementing focus, state, theme, and motion behavior per screen.

## Scope

Included: activation of `@rituvia/ui`, semantic color/typography/spacing/radius/elevation/motion
tokens, system/light/dark and forced-color behavior, native-first action and form controls, status
and loading primitives, caller-owned localized content, usage guidance, Web-shell adoption, unit and
contract coverage, and real-browser verification.

Excluded: a theme preference persistence UI, dialogs/comboboxes/date/location controls, domain or
commerce components, icon artwork, Storybook where no tooling exists, complete empty/offline/
provider-unavailable page patterns owned by RIT-015, additional locale activation, analytics,
database work, remote delivery, and production activation.

## Acceptance criteria

- [x] Central semantic tokens cover color, type, spacing, radius, elevation, motion, and minimum interactive sizing without remote font or image dependencies.
- [x] Core action, field, selection, alert, and loading primitives expose native semantics plus focus, disabled, loading, invalid/error, and accessible-name contracts.
- [x] System/light/dark, reduced-motion, forced-color, 320px/400% reflow, long-content, and RTL behavior are implemented and verified without encoding meaning by color alone.
- [x] The Web shell consumes the shared package without hardcoded production copy, unsafe URL handling, client-only rendering, or a material resource-budget regression.
- [x] Unit/contract tests, real-browser checks, full repository gates, independent review, documentation, and project state are reconciled.

- `pnpm test:unit`: 374 tests in 32 files; focused UI/Web/architecture suites cover public-value
  adversarial cases, SSR semantics, labels/descriptions/errors, Server Component-safe static output,
  controlled/default exclusivity, mixed state, text-control enum/numeric bounds, unsafe input-type
  exclusion, theme cascade, contrast, resource bans, long-content/writing-system fixtures, and narrow
  effective-width rules.
- `pnpm lint`, `pnpm typecheck`, architecture audit, and production build pass across seven active
  modules and 75 audited source files. The build verifier checks 28 artifacts and exact UI source/
  dist CSS parity.
- Latest Web budgets are 5,476 B gzip HTML, 4,758 B gzip CSS, 207,820 B gzip JavaScript, and 356 B
  raw icon. CSS is 1,974 B above RIT-010 and below the reviewed 6 KiB ceiling by 1,386 B.
- Configuration-boundary HTTP integration and the real PostgreSQL foundation suite pass. The UI
  adds no database, storage, analytics, network, environment, or external runtime dependency.
- Independent architecture, dependency/accessibility/localization, and security/privacy reviews
  drove remediation for theme cascade, loading accessible names, unconditional RSC event handlers,
  ambiguous controlled state, duplicate option values, mixed-state divergence, and UI resource/
  JSX-runtime policy escapes. Final adversarial review also closed nested-scope local-link forgery,
  trusted-component rebinding, browser-network aliases, forged branded control values, and an RTL
  ancestor selector that ignored nested `dir="ltr"`. No code P0/P1/P2 remains after remediation.
- Codex Browser live verification at the loopback-only synthetic preview covers the accessibility
  tree, native pointer/form interactions, disabled/loading/mixed/checked states, 44px targets,
  1,280px and 320px/400%-equivalent reflow without clipping or overflow, light/dark/system themes,
  RTL and nested LTR overrides, local-only resources, and zero console warnings/errors. The nested
  LTR fixture keeps its forward icon unmirrored and checked switch at +20px while the outer RTL
  switch moves -20px.
- An owner-authorized isolated Playwright browser completes the remaining matrix against the same
  loopback preview. Twelve Tab stops appear in logical order while disabled controls are skipped;
  Shift+Tab reverses correctly; every stop exposes `:focus-visible` with a 3px solid outline; Enter
  activates the fields anchor; Space toggles the checkbox and switch; arrow keys change the native
  radio selection; and native select typeahead chooses the second option.
- With `prefers-reduced-motion: reduce` actively emulated, `matchMedia` is true, spinner and skeleton
  animation duration collapses to 0.01ms for one iteration, action transitions collapse to 0.01ms,
  and root scrolling is automatic. With `forced-colors: active`, `matchMedia` is true, controls keep
  CanvasText boundaries, focus uses Highlight, checked/mixed indicators and the checked switch track
  use Highlight, and marks/thumb use HighlightText; computed styles and a rendered screenshot show
  the states remain distinguishable.

## Risks and rollback

Primary risks are inaccessible state semantics, a theme override that conflicts with operating-system
preference, unsafe action URLs, CSS or package-boundary drift, and a Web performance regression.
Static/SSR, CSS, architecture, build, HTTP, independent-review, Codex Browser, and Playwright
evidence cover the applicable code, interaction, media-preference, and rendered-layout risks. The
implementation remains a repository-only presentation layer with no database, user preference,
remote, or production mutation. Roll back by reverting the RIT-011 commit and regenerating evidence.

Non-blocking hardening remains explicit: Next.js still needs element-level inline script/style CSP
permission while attributes and emitted artifacts are audited; public error-copy sanitization plus
asynchronous mutation idempotency remain caller responsibilities; and future profile/address forms
must extend the narrow autocomplete allowlist with their reviewed WCAG input-purpose tokens. The
current shell has no sensitive or mutating consumer of those surfaces.
