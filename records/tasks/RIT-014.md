# RIT-014: Accessibility and pseudolocale CI smoke

- Backlog item: RIT-014
- Related records: D-027

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

Every reviewed public shell build is automatically exercised for accessibility, keyboard behavior,
text expansion, and RTL scaffold regressions before the existing Quality job can pass.

## Scope

Included: the exact four English build artifacts; blocking Chromium/axe scans; complete forward and
reverse Tab order; skip-link focus transfer; 44px targets; native locale-option fit; desktop/mobile
layout checks; at-least-40% test-only LTR expansion; test-only desktop/mobile RTL; dark and reduced
motion; meaningful no-JavaScript content; exact same-origin artifact serving; static-path traversal
protection; contrast compensation tests; exact dependency and CI-order contracts; and the minimum
responsive locale-control fix exposed by expanded text.

Excluded: a second supported or public locale, ICU/plural/markup pseudotranslation, reviewed Arabic
content, production activation, screen-reader certification, Firefox/WebKit, visual snapshot
approval, user data, analytics, database changes, and any production or external-system action.

## Acceptance criteria

- [x] All four public routes pass blocking WCAG 2.0/2.1/2.2 AA and best-practice axe scans, with no
      violation or unexpected incomplete result.
- [x] Complete forward/reverse keyboard order, visible unclipped focus, skip-link transfer, 44px
      targets, selected-option fit, and 320px reflow pass.
- [x] Every current English message preserves placeholders and expands by at least 40%; the built
      pages pass expanded LTR and desktop/mobile RTL without exposing pseudolocale routes or links.
- [x] Light/dark, reduced-motion, and independent no-JavaScript contexts remain usable and local
      only; exact gradient contrast incompletes have worst-case mathematical compensation tests.
- [x] Browser/tool versions, the single-browser install, build-before-smoke order, route inventory,
      and artifact-path boundary are pinned by unit and mutation tests.
- [x] Documentation, decision record, generated evidence, queue state, risks, and rollback match the
      verified implementation.

## Verification evidence

Exact Node.js 24.18.0 and pnpm 11.13.1 verification passes 460 unit/contract tests in 37 files, the
88-source architecture policy, strict format/lint/type gates, real configuration and PostgreSQL
integration, and the 31-artifact production build. The RIT-014 focused suite passes 89 tests across
the accessibility, contrast, CI, and build-path contracts. Owner-authorized Playwright/axe acceptance
passes four public routes with 16 scans and 143 exact gradient-background contrast nodes retained
only under source-level worst-case contrast tests, plus complete forward/reverse focus, skip-link
transfer, 44px targets, 40% expansion, desktop/mobile RTL, dark/reduced-motion/no-JavaScript states,
and local-only requests.

## Risks and rollback

Primary risks are stale local build evidence, overly broad axe suppression, a public pseudolocale,
browser network escape, and treating Chromium automation as screen-reader certification. CI enforces
build-before-smoke; dependencies, routes, artifact reads, requests, scan tags, exact incomplete
selectors, and public locale boundaries fail closed. Manual current-screen-reader, Firefox/WebKit,
real zoom, full ICU, and full Arabic review remain explicit later work. Roll back by reverting the
RIT-014 commit; no migration, user data, public endpoint, locale activation, or external recovery is
required.
