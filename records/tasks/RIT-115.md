# RIT-115: Redacted localized one-card share artifacts

- Backlog item: RIT-115
- Related records: D-075, D-085
- Owner approval: Not required for bounded internal implementation and validation; production
  deployment, another language, public share hosting, analytics, provider integration, DNS, and
  public launch remain owner-gated

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

Let an adult user explicitly preview, redact, download, and, where supported, file-share one local
privacy-safe SVG derived from a completed one-card reflection.

## Scope

Included: one-card result integration; exact public-field projection; default bounded theme with a
hide control; governed English ICU accessible description; public Tarot canonical; exact local
SVG preview; local download; capability-checked native file sharing; Blob image CSP; focused
unit, localization, metadata, network, storage, accessibility, and production-artifact browser
evidence.

Excluded: three-card or other product share surfaces; public share URLs; uploads; object storage;
database state; tokens; social preview metadata; traditional artwork; analytics; another locale;
provider integration; deployment, DNS, or public launch.

## Acceptance criteria

- [x] Sharing is opt-in and no artifact preview exists before the user requests it.
- [x] The exact allowlist omits private question, reading ID, interpretation, birth data,
      intention, journal text, account data, and internal errors.
- [x] The bounded selected theme is present by default and one control removes it from alt text,
      SVG bytes, download, and native share.
- [x] The preview is the exact generated 1200 by 630 SVG, with localized accessible text,
      canonical public Tarot URL, brand attribution, and symbolic-not-predictive boundary.
- [x] Unsupported locales, pseudolocales, private/query/fragment/credential URLs, unsafe text, and
      XML injection fail closed.
- [x] Native sharing appears only for a supported SVG file payload and never reports a link-only
      fallback as a shared card.
- [x] The private result page remains noindex and emits no canonical, Open Graph, or Twitter
      metadata.
- [x] Production-artifact Chromium proves private canaries are absent from preview/download/share,
      there is no upload or external request, storage remains bounded, object URLs are revoked,
      and 320px accessibility checks pass.

## Verification evidence

- The immutable `tarot-share-card.v1` projection receives only reviewed public values from the
  one-card flow; private response fields and the reading identifier are never component props.
- The source/runtime localization catalog is version `1.1.0`, checksummed, and contains the exact
  ICU accessible-description contract. Production accepts only `en`; test-only `en-XA`/`ar-XB`
  exercise serializer direction and expansion without entering runtime output.
- The browser gate uses the immutable optimized Next.js artifact, synthetic private canaries in
  displayed result fields, cookie, and storage, and checks the exact Blob, download, and
  `navigator.share` file bytes.
- Local sharing sends no network request, stores no artifact, creates no public URL, and preserves
  the private page's absent canonical/Open Graph/Twitter contract.
- Focused unit/localization tests, Web typecheck/build, CI contract, architecture, records,
  formatting, lint, configuration boundary, secret scan, and the dedicated Chromium gate provide
  task closure without rerunning the complete 1,674-test workspace matrix.

## Risks and rollback

SVG rendering can vary slightly by installed system fonts, so layout uses fixed bounded line
counts, geometry, and local fallback fonts rather than pixel-identical font output. Some browsers
cannot share SVG files; they retain the local download path and do not receive a misleading
link-only success state.

Rollback removes the one-card share component, serializer, localized message, browser gate, and
`blob:` image CSP allowance. No persisted data, migration, customer upload, or external state
requires reversal.
