# RIT-013: SEO metadata, canonical, robots, and sitemap foundation

- Backlog item: RIT-013
- Related records: D-026

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

Search crawlers receive one finite, environment-safe representation of the four reviewed English
public pages, while non-production, query-string, framework, unsupported, and future private routes
cannot be mistaken for indexable content.

## Scope

Included: a typed English indexable-page inventory; exact per-page title, description, canonical,
Open Graph, `en` self-reference, and `x-default`; environment-aware `/robots.txt` with narrowly
reviewed render-asset access; one stable `/sitemap.xml`; production-only page indexing; noindex
response headers for non-production, query-string, served framework, disabled, unavailable,
unsupported, and private-route requests; a private non-cacheable 404 contract for framework-owned
direct `*.rsc` errors; safe-off coverage; built-artifact and real HTTP verification; and local browser
acceptance.

Excluded: production deployment or public-shell activation, canonical-domain/DNS/Search Console
changes, a second locale, localized slugs, sitemap indexes, redirect history, JSON-LD/structured-data
publishing, rich-result validation, editorial freshness integration, analytics, third-party scripts,
new public content, and implementation of future private routes.

## Acceptance criteria

- [x] The typed indexable inventory contains exactly `/en`, `/en/methodology`, `/en/safety`, and
      `/en/privacy`, with stable order and no private, redirect, framework, query, or unsupported URL.
- [x] All four pages emit unique server-rendered title, description, canonical, Open Graph, `en`,
      `x-default`, and environment-correct robots metadata without adding client JavaScript.
- [x] Non-production robots disallow the whole site and publish no sitemap; production robots allow
      only the exact document inventory, reviewed local render assets, and one canonical sitemap.
- [x] The sitemap is valid, deterministic, environment-safe, and contains exactly the production
      inventory without fabricated build-time or editorial `lastmod` values.
- [x] Safe-off, unavailable, unsupported, private, query-string, RSC, segment, and metadata-route
      behavior is fail-closed and cannot emit an indexable response.
- [x] Unit, mutation, build, real HTTP, browser, security/privacy, accessibility, localization, and
      performance checks pass with no remote resource or database migration.
- [x] Documentation, decision record, generated evidence, queue state, and rollback notes match the
      verified implementation.

## Verification evidence

Exact Node.js 24.18.0 and pnpm 11.13.1 verification passed 432 unit/contract tests in 35 files, the
84-source architecture policy, strict type/lint/format gates, an isolated production build and real
HTTP configuration matrix, the PostgreSQL foundation, dependency audit, and a 31-artifact workspace
build. The production matrix covers canonical/generic HTML, metadata host and robots polarity,
robots/sitemap on/off/error state, bare/spoofed/reviewed/direct/segment RSC, private/query/internal
paths, and post-request sensitive-log canaries. Owner-authorized Playwright verified four unique
200 pages, exact local noindex metadata/headers, robots disallow-all, absent local sitemap, private
and query 404s, RSC cache/index boundaries, 320px reflow and 44px targets, visible 3px skip-link
focus, no-JavaScript readability, zero console messages, and 81 same-origin requests.

## Risks and rollback

Primary risks are accidentally indexing preview content, allowing prefix-matched private paths,
listing unavailable or framework representations, publishing a misleading freshness timestamp,
or coupling crawl policy to user data. The implementation remains a pure finite allowlist behind
the existing `experience.public_shell` safe-off gate, adds no user input, storage, analytics,
provider, payment, locale, or database change, and performs no production action. Roll back by
reverting the RIT-013 commit; no migration or data recovery is required.
