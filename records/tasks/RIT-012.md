# RIT-012: Public positioning, methodology, safety, and privacy pages

- Backlog item: RIT-012
- Related records: D-025

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

An anonymous English visitor can understand what RITUVIA is, how symbolic reflection is intended to
work, what the product will never determine, how privacy is designed, and where the meaningful free
path fits before sharing personal information or encountering an account or payment gate.

## Scope

Included: the existing `/en` positioning page plus exact `/en/methodology`, `/en/safety`, and
`/en/privacy` public routes; typed English source messages; shared navigation/page framing;
route-specific title, description, canonical, Open Graph, robots, safe-off proxy, build/resource,
accessibility, reflow, and browser evidence; and truthful foundation-status language.

Excluded: legal privacy terms or consent text, crisis-resource publication, contact/support flows,
pricing, accounts, readings, calculators, payments, a second locale, sitemap work owned by RIT-013,
structured-data work owned by RIT-114, production activation, analytics, storage, database changes,
and any claim that an unfinished feature or external approval exists.

## Acceptance criteria

- [x] The product-positioning home page and three finite public trust routes provide useful,
      non-duplicative server-rendered content with one clear next step and a meaningful free-path
      explanation.
- [x] Methodology separates deterministic facts, curated source content, bounded AI explanation,
      user reflection, limitations, and the finite Question to Revisit loop.
- [x] Safety copy preserves agency and rejects professional/high-stakes certainty, supernatural
      authority, fear, dependence, paid efficacy, coercion, and outcome guarantees.
- [x] Privacy copy accurately separates the current personal-input-free foundation from planned private
      features and is visibly a design summary, not an approved legal privacy notice.
- [x] Exact locale-prefixed routing, safe-off HTML/RSC coverage, metadata, navigation, no-JavaScript
      readability, keyboard/focus, 320px/400% reflow, theme/media preferences, and local-only
      resources are verified.
- [x] Unit/contract tests, full repository gates, independent review, documentation, generated
      evidence, and project state are reconciled.
- [x] The owner explicitly approves the exact English safety and privacy-design copy before this
      task is marked Done; this approval does not activate or deploy the public shell.

## Verification evidence

Focused routing/message/metadata/SSR/proxy/build-policy tests pass. The production build emits all
four exact routes and the build policy reports maximum gzip sizes of 5,548 B HTML, 4,965 B CSS, and
207,803 B JavaScript within the unchanged budgets. Owner-authorized Playwright checks prove HTTP
200, one H1, current navigation, 44px targets, no personal form controls, 320px/400%-equivalent
reflow without overflow, visible forward/reverse keyboard focus and skip transfer, Enter navigation,
light/dark/system themes, reduced motion, forced colors, complete no-JavaScript content, zero
console warnings/errors, and same-origin-only requests. Full repository, generated-evidence,
dependency-audit, and independent-review results passed before the owner-approved final state.

## Risks and rollback

Primary risks are publishing legal or crisis copy without approval, implying unfinished readings or
privacy controls exist, weakening the exact safe-off route boundary, introducing duplicated/thin
content, leaking private data through metadata, and exceeding page/resource budgets. The routes
remain repository-local and behind the existing `experience.public_shell` server gate; no database,
personal data, analytics, provider, payment, locale, or production state changes. Roll back by
reverting the RIT-012 commit and regenerating evidence.
