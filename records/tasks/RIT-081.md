# RIT-081: Deterministic numerology engine

- Backlog item: RIT-081
- Related records: D-064

The queue state, priority, milestone, dependencies, and owner gates remain canonical in

## Outcome

The repository provides one pure, deterministic, version-bound V1 engine that calculates Life
Path, Birthday Number, and Personal Year from canonical input and returns inspectable formula
evidence matching every approved worked vector.

## Scope

Included: strict request parsing; proleptic-Gregorian date validation; explicit target-year
handling; ASCII decimal digit evidence; exact 11/22/33 reduction; immutable versioned facts;
approved catalog/rule/rule-set binding; stable non-content-bearing errors; fixed-vector, edge,
negative, determinism, and traversal-based property tests; and affected-package evidence.

Excluded: names or Expression Number, transliteration, localized or non-Gregorian input
conversion, interpretation prose, AI, API, persistence, migrations, analytics, UI, SEO,
deployment, and public launch.

## Acceptance criteria

- [x] Request input is exact, immutable, ASCII ISO date plus explicit four-digit target year; extra
      name/script/clock/locale fields fail closed.
- [x] Life Path, Birthday Number, and Personal Year match D-064 and expose canonical digits,
      initial value, every reduction step, final value, and master-number preservation.
- [x] Results bind exact catalog, rule-set, individual rule, reduction policy, engine, and schema
      versions without accepting client-authored result authority.
- [x] Approved worked vectors, leap/century dates, zero-containing dates, 11/22/33, invalid dates,
      whitespace, localized digits, unsupported scripts, unknown fields, and deterministic replay
      pass focused tests.
- [x] Traversal-based property tests prove every valid result is in `1..9`, `11`, `22`, or `33`,
      every step is derivable, input is not mutated, output is deeply immutable, and no clock,
      randomness, network, storage, environment, AI, or host locale is used.
- [x] Formatting, linting, affected typecheck/build, architecture, records, generated evidence,
      instruction-pack, and secret checks pass without the unrelated full test matrix.
- [x] Backlog, status, decision/task records, record index, manual, and checksums reflect the
      verified slice.

## Risks and rollback

Formula drift would silently change symbolic facts, so every output and fixture binds exact
versions and later variants require successors. Birth dates are sensitive even though this engine
does not store, log, or transmit them. An explicit target year prevents time-dependent replay.
Names and localized scripts are rejected rather than silently normalized.

There is no migration, API, UI, retained data, provider, feature activation, or deployment. Roll
back by removing the unused engine/tests/exports and restoring the records and generated evidence.
Once a later task persists results, historical versions must remain replayable.
