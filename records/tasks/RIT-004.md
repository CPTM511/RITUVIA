# RIT-004: Create the hosted CI quality gates

- Backlog item: RIT-004
- Related records: None
- Owner approval: the private GitHub remote and cumulative commit/push were owner-authorized on
  2026-07-29; production deployment and public source disclosure remain separately gated

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

Establish the repository-owned GitHub Actions quality, PostgreSQL integration, and security jobs,
protect them on `main`, and capture one passing hosted run before closing the M0 CI foundation.

## Scope

Included: immutable GitHub Action references; read-only workflow permissions; locked dependency
installation; format, lint, type, unit, build, accessibility, browser, configuration, architecture,
records, migration, AI evaluation, editorial, localization, SEO/GEO, RTL, writing-system,
PostgreSQL, secret, dependency, native supply-chain, and Corresponding Source gates; protected
required checks; hosted evidence.

Excluded: production deployment, customer data, production secrets, DNS, indexing, payment or AI
provider activation, public repository visibility, and weakening any local or release gate.

## Acceptance criteria

- [x] The workflow defines separate `Quality`, `PostgreSQL integration`, and `Security scans` jobs.
- [x] Actions and the PostgreSQL service are pinned to immutable revisions or image digests.
- [x] The workflow uses read-only repository permission and no production secret or environment.
- [x] The PostgreSQL job builds its internal runtime dependency before executing the verifier.
- [x] The PostgreSQL job generates its Prisma client from a clean checkout before importing DB code.
- [x] Analytics verification builds its observability runtime dependency from a clean checkout.
- [x] The pinned actionlint downloader uses the official Linux AMD64 asset and checksum.
- [x] Full-history Gitleaks ignores only 11 exact reviewed test-constant fingerprints.
- [x] CI contract tests enforce the workflow and database-job boundaries.
- [x] A private GitHub remote exists and the historical `main` revision produced a hosted run.
- [ ] Required status checks and workflow changes are protected on `main`.
- [ ] One current hosted run passes all three required jobs.

## Risks and rollback

GitHub still returns HTTP 403 for private-repository branch protection until GitHub Pro is active
or the repository is made public. Public visibility is not implied by the project's AGPL license
and remains a separate owner decision. RIT-004 cannot be marked Done until protection and a
passing hosted run both exist.

Rollback reverts the CI closure commit or disables the candidate branch without changing
production systems. The protected historical `main` revision remains available, and no customer
data, production secret, deployment, DNS, or provider state is touched.
