# RIT-009: Repository decision, task, incident, and experiment workflow

- Backlog item: RIT-009
- Related records: D-022

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

Every future active implementation task and every durable decision, incident, or experiment has a
stable, linked, machine-checked repository record without duplicating the canonical task queue.

## Scope

Included: contribution rules, record templates/index, a first task and decision record, task-result
links and semantics, fail-closed record/generated-evidence gates with CI coverage, and deterministic
index-then-manual-then-checksum generation.

Excluded: external issue trackers, hosted CI evidence, remote branch protection, production incident
systems, real experiments, production deployments, and any owner-gated business action.

## Acceptance criteria

- [x] Canonical status/dependency/decision ownership is explicit and task records cannot duplicate queue fields.
- [x] Stable decision/task/incident/experiment filenames, headings, sections, references, and index coverage are enforced.
- [x] Structured task-result output requires bounded trace metadata, typed record references, rollback notes, and safe outcome semantics.
- [x] Local and active-CI evidence chains run the record/generated-evidence gates and mutation tests cover bypasses.
- [x] One synchronizer renders the compact index, compiled manual, and tracked-file checksums in that exact order.
- [x] Full verification, independent review, documentation, and project state are reconciled.

## Risks and rollback

The main risks are false-positive record parsing, a schema change that automation fails to adopt, and
generated evidence refreshed in the wrong order. Fixtures and mutation tests lock the grammar;
prompts and a synthetic example adopt the schema in the same change; the synchronizer owns order.
Rollback is repository-only: revert the RIT-009 commit and regenerate evidence. Existing owner gates
and production state are unaffected.
