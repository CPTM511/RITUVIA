# RIT-035: Tarot AI interpretation polling UX

- Backlog item: RIT-035
- Related records: D-034, D-040, D-041, D-042

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

RIT-035 adds the private final-only browser/API boundary that can turn a fixed one-card or
three-card reading into an explicitly requested, independently checked interpretation while the
real provider runtime remains hard safe-off.

## Scope

Included: a strict four-arm public response; closed redacted final-output projection; explicit
owner-bound same-origin UUID-idempotent POST start; separate side-effect-free GET status polling;
bounded response bytes and `Retry-After`; shared lazy-loaded one-/three-card panel; cancellable
foreground polling; stale-response rejection; same-operation manual retry; accessible localized
loading/failure/final states; exact verified-AI, reviewed-fallback, privacy, and safety labels;
proxy/build registration; and hard-safe-off runtime adapters.

Excluded: a real provider, reviewer, model, SDK, key, network call, paid inference, production
catalog/content/prompt/fallback/safety activation, provisional prose display, a new persistence
shape or retention period, regeneration/history, analytics, accounts, payment, deployment, and
public launch.

## Acceptance criteria

- [x] One exact private route starts interpretation only through an explicit owner-bound
      same-origin bodyless POST with a strict UUID V4 idempotency key, and polls through a separate
      owner-bound no-store GET that cannot invoke work.
- [x] The public contract accepts only processing, verified, reviewed-fallback, or failed; marks
      processing/failure non-displayable; binds the exact reading ID; rejects extra/private keys,
      malformed text, unsafe URLs/markup, schema drift, and oversized bytes; and recursively freezes
      parsed values.
- [x] Only a durable verified or reviewed-fallback result can reach rendered prose. Provisional,
      pending-verification, childless historical, provider, reviewer, provenance, digest, claim,
      lease, token, and cost data never enter browser bytes.
- [x] The shared one-/three-card client requires an explicit start; permits one in-flight request;
      polls with abortable non-overlapping foreground timeouts; stops after eight polls; rejects
      stale responses; supports cancellation; and reuses the original operation ID only for manual
      transient retry.
- [x] English copy is extracted into typed locale resources. Verified AI, reviewed non-AI fallback,
      privacy, limitation, loading, offline, error, retry, rate-limit, session, permission,
      not-found, conflict, invalid-response, and unavailable states have semantic labels, focus/live
      behavior, keyboard controls, and mobile-compatible layout.
- [x] The production/local runtime remains hard safe-off and makes no provider, reviewer, model,
      credential, network, paid-inference, database, payment, or analytics call from this new route.
- [x] Contract, machine, transport, panel, route, runtime, proxy, message, architecture,
      configuration, production-build, accessibility, and full unit/contract tests pass without
      weakening budgets or existing safety gates; no database code or migration changed.

## Risks and rollback

The complete transport/UI boundary is not a claim that AI is production-active. Ordinary runtime
composition deliberately returns a safe unavailable response until catalog, content, provider,
model, reviewer, safety, budget, and deployment approvals are all satisfied. RIT-036 still owns the
fixed release eval gate, and RIT-122 still owns production denial-of-wallet controls.

Rollback removes the unused route, runtime adapters, client contract/state/transport/panel, message
keys, tests, and build registration. No migration or durable data change is introduced. If a future
approved adapter is activated, rollback must disable that adapter while retaining existing durable
records under their current parent expiry; destructive deletion remains a separate owner gate.
