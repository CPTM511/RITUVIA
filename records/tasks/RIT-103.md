# RIT-103: Localized routes, slugs, hreflang, sitemaps, and redirects

- Backlog item: RIT-103
- Related records: D-026, D-074, D-075, D-076

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

RITUVIA now has one approval-bound, stable-ID public route matrix that drives locale-specific
slugs, static routes, canonical metadata, reciprocal hreflang, production robots, locale/content
sitemaps, and explicit redirect history without activating an unreviewed locale.

## Scope

Included: canonical BCP 47 locale and finite slug validation; approval/content/reviewer binding;
stable public content IDs; generic one- and two-segment public pages; locale-derived SSR document
language/direction; canonical and reciprocal alternate generation; sitemap index and exact
English pages/numerology/astrology URL sets; substantive `lastmod`; exact redirect registry and
same-locale 308 execution path; fail-closed duplicate, default-locale, query, RSC, private, and
unsupported behavior; source-bound client-safe ICU runtime projection; focused unit, type, build,
HTTP, accessibility, and repository evidence.

Excluded: activating another locale; translating or machine-publishing content; language
switching; country selection; localized email/support/payment/legal/safety content; invented legacy
aliases; Search Console; analytics; structured-data eligibility expansion; production deployment;
DNS; and public launch.

## Acceptance criteria

- [x] Stable content IDs resolve only to exact reviewed locale-specific segments and substantive
      revision dates.
- [x] Route admission fails closed without canonical locale tags, default-locale content, unique
      paths, approval reference, content version, reviewer, and review date.
- [x] Generic localized public routes render the fourteen approved English documents and bind SSR
      `lang`, `dir`, canonical, Open Graph, JSON-LD links, and internal links to the same registry.
- [x] Every published route emits self hreflang and `x-default`; synthetic multi-locale tests prove
      reciprocal same-route alternates without entering the production registry.
- [x] `/sitemap.xml` indexes exact non-empty locale/content-type shards; every shard contains only
      its approved routes, timestamps, and reciprocal hreflang links.
- [x] Redirect history accepts only explicit same-locale stale slugs and current approved targets;
      unknown, query, encoded, private, cross-locale, and chained/colliding inputs fail closed.
- [x] Git history confirms no superseded production public slug, so the production redirect
      registry is intentionally empty rather than populated with invented aliases.
- [x] Preview/local/staging, disabled/unavailable, private, query, and framework representations
      remain absent from public crawl output and noindex.
- [x] Client-static assets contain no source rights, server-only configuration, or fallback brand
      literal from the localization workflow.
- [x] Documentation, durable records, queue state, rollback, and owner gates match implementation.

## Verification evidence

Focused Vitest passes 291 tests across 11 route registry, routing, metadata, SEO, proxy, publication, shell contract,
and build-policy tests. Web and i18n type checks pass. The production build generates all fourteen
approved public routes under `/[locale]/[page]` and `/[locale]/[page]/[slug]`; the shell artifact
policy reports no findings.

The real HTTP configuration boundary passes typed parsing, fail-closed startup, server-only
imports, client-delivery isolation, production sitemap index/shards, disabled/unavailable
discovery, exact canonical HTML, RSC/query/private rejection, and secret canaries. The production
artifact accessibility run passes fourteen public and three private routes with 79 Axe scans, 40%
expansion, desktop/mobile RTL, forward/reverse keyboard focus, 44px targets, dark/reduced-motion,
no-JavaScript, offline, and local-only request checks.

The complete 1,674-test workspace suite is intentionally deferred under D-050 because RIT-103 is
an ordinary focused task rather than a milestone integration or release-candidate gate.

## Approval outcome

No owner gate is crossed. English remains the only supported and published locale. OWN-004 and
RIT-105 still gate the first Tier 1 locale/country; RIT-104 gates localized messages; RIT-106 gates
reviewed beta content and support readiness; production deployment and crawl activation retain
their existing owner gates.

## Risks and rollback

The main future risk is treating route architecture as translation or launch approval. The
registry therefore requires explicit publication evidence and contains no non-English production
record. Roll back by reverting D-076 implementation files; no database, customer data, provider,
DNS, or redirect state requires restoration.
