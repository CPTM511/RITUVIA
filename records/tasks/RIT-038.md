# RIT-038: Privacy-safe AI cost, latency, fallback, and safety operations

- Backlog item: RIT-038
- Related records: D-040, D-041, D-042, D-088
- Owner approval: Not required for bounded offline aggregate processing and verification;
  production provider/model activation or change, safety-policy change, admin route, durable
  production reader, monetary budget, automated enforcement, deployment, or launch remains gated

The queue state, priority, milestone, dependencies, and owner gates remain canonical in
[BACKLOG.md](../../BACKLOG.md).

## Outcome

Provide one deterministic, private, source-labeled AI operations brief for cost, latency, retries,
failures, reviewed fallbacks, and safe replacements without exposing interpretation content or
claiming unavailable production performance.

## Scope

Included: strict daily aggregate schema; source/freshness state; model/provider/prompt/content/
schema/safety version grouping; low-sample suppression; cost/token reporting coverage; estimated
cost; latency and 30-second review rate; retries; failures; reviewed fallbacks; verified and safe
replacement outcomes; human-review thresholds; digest-bound private JSON/Markdown; CI/build
contracts; operations documentation.

Excluded: production database reader; provider/model call; raw logs/traces; private prompts or
outputs; browser/product analytics; user/reading/payment identifiers; critical safety inference;
admin UI/API; monetary budget creation or enforcement; model/prompt/safety changes; deployment.

## Acceptance criteria

- [x] Strict parsing accepts only aggregate operational fields already authorized by D-040/D-041
      and rejects unknown/private fields and accessors.
- [x] Exact daily window, capture lag, source label, approval, and freshness are visible.
- [x] Unavailable, stale, or synthetic evidence blocks decisions and yields null performance
      values.
- [x] Overall and version-group values require at least 20 generations.
- [x] Cost, token, latency, retry, failure, reviewed fallback, completion, and safe-replacement
      metrics expose definitions, numerators, denominators, and known gaps.
- [x] Version groups expose locale, reading type, provider/model, prompt, output schema, safety
      policy, and approved content versions without identifiers or prose.
- [x] Threshold alerts require human review and cannot change production or weaken safety.
- [x] Missing cost is never zero; monetary budget status remains unavailable pending OWN-005.
- [x] CLI binds the real input SHA-256, rejects symlinks and oversized inputs, writes mode-0600
      files, and never overwrites evidence.
- [x] Focused type, unit, CLI, architecture, CI-contract, record, lint/format, and build-export
      checks pass without rerunning the full workspace test matrix.

## Verification evidence

- Analytics tests cover strict parsing, private-field and accessor rejection, aggregate
  consistency, stale/synthetic/unavailable behavior, low-sample suppression, metric math, alerts,
  and forged renderer input.
- CLI tests cover actual byte digest, private mode, exclusive output, and symbolic-link denial.
- The dedicated verifier exercises current, stale, synthetic, unavailable, injected, and
  threshold-crossing fixtures without database/provider/model/network access.
- CI requires `pnpm check:ai-operations`; the analytics build contract requires the compiled
  projection and Markdown renderer.

## Risks and rollback

Production AI is safe-off, so real cost, latency, provider health, and runtime safety replacement
rates remain unavailable. Aggregate means do not provide p50/p95 latency, and provider-estimated
cost is not invoice evidence. RIT-120 must preserve source/freshness labels; RIT-127 must obtain
budget approval before enforcement.

Rollback removes the analytics module, report CLI, focused tests, CI/build gate, and decision
record. No migration, persisted user data, provider state, or production action requires reversal.
