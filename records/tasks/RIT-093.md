## Outcome

The owner-approved AGPL transition removes the superseded Professional License purchase gate.
RITUVIA now has a strict Selection V2, an immutable upstream source/data manifest, an independently
verified readiness input, a registered server-only native package, a bounded process-isolated C
bridge, checksum attestation, hardened offline build, native SBOM, reproducible binary check, and a
provider-neutral natal-facts contract.

Exact time can produce eleven tropical placements plus explicit house cusps, Ascendant, MC, ARMC,
Vertex, requested/returned flags, method identifiers, uncertainty, and complete build provenance.
Approximate time uses only the supplied center instant and suppresses houses, angles, and aspects.
Unknown time never invokes the native engine and returns no placements.

The approved method is now bound to an authorized birth-profile revision in a server-only
application service. Calculations are encrypted, append-only, replay-safe, owner-scoped, exported
through `privacy-export-package.v2`, and cryptographically shredded by the privacy-deletion path.
The additive PostgreSQL migration and default-off `experience.astrology` kill switch exist. An
isolated PostgreSQL drill now proves off, approved on, emergency off, immutable history,
least-privilege reads, and logical restore without enabling a deployed environment.
The Web server runtime now composes database persistence, private-content cryptography, live
feature-flag evaluation, a production-only metadata loader, checksum-attested native execution,
and the pure natal adapter without adding a public route.

The exact upstream commit now has a fail-closed OSV query gate, and a native-component
Corresponding Source archive has been extracted and rebuilt with curl replaced by a rejecting
shim. The normal and sanitizer-native gates now also compare forty geocentric apparent
ecliptic-of-date vectors against pinned MIT Astronomy Engine `2.1.19` across 1801, 1888, 2000, and 2050. A clean ephemeral Ubuntu arm64 environment now passes Linux ASan+UBSan, 151 deterministic
mutation cases, and 5,000 libFuzzer runs from the archived component source.

The exact-clean complete release-source gate passed revision
`1fded12559b4e2986a317f2a6fee4008a2c22b8a`. It combined all tracked source with the pinned native
source/data, verified a 914-file inventory, and repeated the native rebuild without network access.
The resulting local archive SHA-256 is
`68cc39041511e1de29fa9355efc512d065c32612e88d396d6dbfe9aebafb4ae6`.
D-072 assigns upload, public-link, and deployed-revision binding to the owner-approved RIT-142/143
release path because no deployed revision exists yet. No API route, UI, production migration,
deployment, public source endpoint, or production activation is added.

Publish exact-time tropical planetary positions and True Node only. Defer houses, angles, and
aspects to a later approved method version. This minimizes cultural/method assumptions but does not
complete the M9 product scope.

## Risks and rollback

The independent corpus materially checks ten geocentric placements but does not cover True Node or
Placidus-house calculations. OSV returned zero records for the pinned commit, but commit-level
database coverage is not a guarantee that every C/C++ vulnerability is known. The local archive is
not a public source offer. D-069 and D-072 require the exact deployed-version execution,
upload/re-download verification, public link, and deployed-revision binding before RIT-143 can
authorize rollout.

Rollback keeps D-069 and the AGPL obligations for any distributed version, disables the native
package, removes generated `.native-cache` artifacts, and stops new calculation composition.
Because the migration is additive and persisted facts are immutable, rollback retains encrypted
rows and operation evidence; destructive removal requires a later approved forward migration. No
route, deployment, production migration, or public source offer exists in this slice.
