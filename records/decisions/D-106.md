## Context

The Owner approved Option A exactly as recommended in the 2026-08-02 OWN-005 decision request.
Option A is the safe-off posture for the already-approved protected English anonymous free Beta. It
does not contain provider quotes, exact amounts, a currency/FX rule, an effective period, alert
destinations, or a durable concurrent spend-admission contract.

The same Owner message also requested that RIT-127 be completed. That request conflicts with the
approved Option A text, which explicitly keeps RIT-127 Blocked until an exact Option B proposal and
the durable runtime evidence exist. The missing monetary and provider facts cannot be inferred.

## Decision

Approve OWN-005 Option A exactly as written:

- all non-essential paid AI, payment, notification, marketing, affiliate, and hosted-lookup spend
  remains disabled for the protected free Beta;
- no placeholder or zero-value amount is represented as an approved operating budget;
- safety, payment integrity, backups, privacy rights, and existing entitlements remain outside
  automatic budget degradation;
- repository-local RIT-128 failure exercises may proceed without a provider or external request;
- provider onboarding, credentials, contracts, production activation, deployment, DNS, public
  access, and launch remain unapproved.

OWN-005 remains Blocked for the exact operating and paid-launch envelope because Option A defers,
rather than supplies, that evidence. RIT-127 remains Blocked under its existing acceptance criteria.
It may be completed only after the Owner supersedes this safe-off posture with Option B's exact
policy artifact and the durable atomic reserve/commit/release/reconcile plus fixed alert contract
passes. RIT-127 must not be marked Done merely because all paid-provider paths are currently off.

## Alternatives considered

| Option | Benefits | Costs/risks | Decision |

| Mark RIT-127 Done under safe-off | Fast status closure | Contradicts approved Option A and hides missing runtime controls | Rejected |

## Consequences

The free deterministic core loop remains independent of paid providers. The repository may exercise
provider-unavailable, timeout, retry, reconciliation, containment, kill-switch, and restore paths
without spending money. No cost ledger, provider adapter, alert service, or migration is added only
to change task status.

RIT-128 can close on repository-local evidence while standing staging, external pager/status
delivery, provider-level restore, external DAST/penetration testing, and Gate H remain incomplete.

There is no rollout. The decision preserves the existing safe-off state. Superseding it requires a
new Owner-approved exact policy artifact; ordinary code or documentation changes cannot activate
spend. Rollback restores the prior unresolved OWN-005 record without changing provider or customer
state.
