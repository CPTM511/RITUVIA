# D-109: Derive Gate H evidence state from eight digest-bound controls

- Date: 2026-08-02
- Owners: operations, qa_security, security
- Related tasks: RIT-129, RIT-130
- Evidence references: `docs/runbooks/RIT-129_STAGING_GATE_H_EVIDENCE.md`;
  `docs/reports/RITUVIA_RIT_129_STAGING_GATE_H_EVIDENCE_2026-08-02.md`;
  `docs/codex/rituvia-production-2026-07-23/11_PRODUCTION_READINESS_GATES.md`; D-104

## Context

Local SLO, restore, incident, case, and Owner-dashboard evidence could not prove standing staging,
provider recovery, external security, or every Gate H requirement.

## Decision

Use one provider-neutral, no-secret staging/Gate H evidence contract with eight ordered controls:
protected staging configuration, invite ingress, aggregate monitoring/alerting, provider
backup/PITR/restore, kill-switch/provider-outage exercise, independent security testing,
support/refund/admin/audit workflow, and release rollback/evidence preservation.

Bind evidence to one revision, bounded path, SHA-256, environment, time, and outcome. Fix Node/pnpm,
artifact/config/lockfile/Corresponding Source digests, D-104 values, and isolated safe-off staging.

Derive state rather than accepting a completion claim. `WORKTREE`, dirty, local, missing, stale,
future, failed, digest-mismatched, or environment-incompatible evidence keeps Gate H incomplete.
Even a complete package reaches only `evidence_ready_for_owner_review`; deployment remains false
until a separate explicit Owner gate.

## Alternatives considered

Deriving eight controls was selected. Reusing the coarse dashboard, accepting `gateHComplete`, or
deploying staging was rejected because each weakens evidence or crosses provider/Owner gates.

## Consequences

RIT-129 can close as a contract while Gate H stays incomplete. No product/Admin surface, database,
secret, provider SDK/resource, or release authority is added.

## Validation

Tests cover strict shape/thresholds, environment/revision/freshness/digests, symlinks/paths/
overwrite, mode `0600`, derived state, and Owner authorization. The CI evidence gate runs
`pnpm check:staging-gate-h`.

## Rollout and rollback

There is no rollout. Rollback removes the local module, scripts, tests, commands, and records; no
external state changes.

## Sources and approvals

- RIT-129 was Ready after D-104/RIT-121/124/128; Gate H/root approval rules remain authoritative.
- Independent review required separate restore, drill, support/admin, rollback, candidate, and
  external-security controls; no external or launch authority was granted.
