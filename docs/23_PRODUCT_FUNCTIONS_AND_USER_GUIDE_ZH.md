# RITUVIA 普通用户快速指南

> 适用对象：在本地或受保护环境中评审 RITUVIA 的成年用户
>
> 当前界面语言：英语
>
> 阅读这份指南不需要技术背景
>
> 这不是已经批准公开发布的中文产品文案

## RITUVIA 是什么

RITUVIA 是一个用于象征性自我反思、个人仪式和私密记录的数字空间。

它帮助你把一个问题或主题转化为：

`新的观察角度 → 自己选择的意图 → 一个小行动 → 一次仪式 → 私密记录 → 日后回看`

RITUVIA 不预测确定的未来，不读取他人的想法，也不替代医疗、法律、心理、财务或其他专业建议。

## 第一次体验

你不需要先注册或付款。

1. 选择 **Begin a free reading**。
2. 选择一个与你有关的主题，例如自己、工作或变化。
3. 可选填写一个问题，然后选择 **Review my question**。
4. 如果问题适合象征性反思，选择 **Continue to a private one-card reflection**；如果页面建议更
   安全的表达，必须由你主动采用并再次检查。高风险或紧急状态不会出现继续解读按钮。
5. 在单张页选择 **Draw one card**，然后揭示结果。
6. 阅读卡牌提供的观察角度、局限、反思问题和小行动建议。
7. 如果内容对你有帮助，选择 **Continue to a private intention**。
8. 写下一个由你自己能够执行的意图和小行动。
9. 选择免费的蜡烛或线香仪式。
10. 完成仪式后，写下一段只属于你的反思。
11. 如果愿意，安排一次 Revisit，在未来回看这次行动带来的真实变化。

安全检查只把你选择的主题一次性交给单张页，不会把问题原文带入解读、URL、浏览器历史、
analytics 或持久存储。

你可以在任何一步停止。产品不会要求你为了获得基本价值而注册、付款或连续重复抽取。

## 如何理解一次解读

一次解读会提供：

- 抽到的卡牌和方向。
- 这张牌可能邀请你注意的内容。
- 其他可能的理解角度。
- 这张牌不能替你决定的事情。
- 一个反思问题。
- 一个可以考虑的小行动。

这些内容是反思材料，不是命令或保证。你最了解自己的现实情况，也始终拥有最终决定权。

如果内容不适合你的情况，可以忽略、重新表达主题，或结束这次体验。

## 创建意图和小行动

一个合适的意图应当：

- 以你自己的选择和行为为中心。
- 不试图控制另一人的感受、决定或行为。
- 可以在现实生活中安全尝试。
- 足够小，便于开始。
- 允许你之后调整或放弃。

例如，与其写“让对方回来”，可以写“给自己一天时间整理感受，再决定是否进行一次尊重边界的沟通”。

## 完成免费仪式

免费的蜡烛和线香仪式会一直保留。付费不会让仪式更有效或更“灵验”。

你可以选择：

- 标准视觉体验。
- 更直接的线性体验。

仪式过程中可以暂停、恢复或退出。关闭声音、减少动态效果或使用键盘不会影响完整体验。

## 写下私密反思

仪式完成后，你可以记录：

- 此刻注意到的一件事。
- 想尝试的小行动。
- 希望未来重新查看的内容。

反思记录默认私密。不要在公开分享图片中加入不希望他人看到的个人信息。

## 安排 Revisit

Revisit 是一次温和的回看邀请，不是必须等待的解锁条件。

1. 选择希望回看的意图。
2. 选择明天、七天后或其他日期。
3. 到合适的时间后，记录真实发生了什么。
4. 完成、改期、归档或删除这次回看。

结果标签只用于整理经历，不表示预言得到验证。

## 安全边界

以下情况不适合继续进行象征性解读：

- 你或他人正面临立即的人身危险。
- 你需要医疗、法律、财务或其他专业判断。
- 你希望产品证明另一个人的思想、忠诚或行为。
- 你希望获得死亡、疾病、怀孕、犯罪、投资或法律结果的确定答案。

遇到紧急危险时，请优先联系当地紧急服务、可信任的人或合资格专业人员。

## 使用中的无障碍选择

你可以使用键盘、减少动态效果和线性仪式模式完成核心步骤。

如果视觉仪式难以使用，请选择线性体验。如果页面没有响应：

1. 保留当前页面，不要连续重复提交。
2. 检查网络连接。
3. 选择页面提供的重试操作。
4. 如果仍不可用，安全退出并稍后重新开始。

如果屏幕阅读器、放大显示或其他辅助技术无法完成某一步，请停止操作并反馈具体页面和步骤；不要用反复提交绕过障碍。

## 当前体验范围

当前在本地或受保护环境中评审的主线是：免费解读、意图、小行动、免费仪式、私密记录和 Revisit。

账户、购买、增强解释、占星、提醒和公开服务不属于这份快速指南，也不应被理解为已经公开开放。

## 一句话记住

RITUVIA 提供一个反思角度；现实、价值观和选择始终属于你。
